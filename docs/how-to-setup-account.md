# アカウントのセットアップ方法（Canvaテンプレートを含む）

Instagramアカウントごとに、カルーセルは**1つのCanvaブランドテンプレート**から生成されます。Canvaとの接続はアプリ全体で1回だけ設定し、テンプレートはアカウントごとに選びます。

> **新しいアカウントを作るときは、テンプレートに画像欄（`s2_image` など）も追加してください。** 21個のテキスト欄に加えて、画像を載せたいページに画像欄（`s1_image` 〜 `s8_image`）が必要です。欄が無いと、AIが画像を選んでも（または生成しても）スライドには載らず、テンプレートのデザインのままになります。詳しくは「B. 画像欄を追加する」を参照してください。画像を使わないアカウントなら、画像欄は不要です。
>
> **このテンプレートはコンテンツ生成に使われます。** 投稿を作成するたびに、エージェントが書いた文章（21項目）がこのテンプレートに自動で流し込まれ、8枚のスライド画像として書き出されます。
> 生成（作成）したテンプレートは、必要に応じて**Canva上でいつでも修正**できます（デザイン、色、レイアウト、素材など）。修正後は「ブランドテンプレートとして公開」し直すと、以降の投稿に反映されます。ただし、各テキストの**項目名**と**文字数の上限**は変えないでください（詳細は後述の「テンプレートの修正」を参照）。

```
1回だけ（ワークスペースごと）            アカウントごと
┌──────────────────────────┐      ┌──────────────────────────────────────┐
│ A. Canvaインテグレーション │      │ B. ブランドテンプレートの作成と公開    │
│ C. 認可（bootstrap）      │ ───▶ │ D. アカウント追加とテンプレート選択    │
└──────────────────────────┘      │ E. ガイドライン設定とコンテンツ生成    │
                                  └──────────────────────────────────────┘
```

## 前提条件

- **Canva Enterprise** アカウント（ブランドテンプレートと自動入力は Enterprise 限定です）
- Turso の設定（`TURSO_DATABASE_URL`、`TURSO_AUTH_TOKEN`）と `OPENAI_API_KEY`
- スキーマの適用: `pnpm --filter @ama/db setup:turso`

## A. Canvaインテグレーションの作成（1回だけ）

[Canva Developer Portal](https://www.canva.com/developers/) で次を行います。

1. **Integration**（Connect アプリ）を作成します。
2. **Authentication → Authorized redirects** に、次の URL を**そのまま**追加します。
   `http://127.0.0.1:8765/callback`
   （`localhost` ではなく `127.0.0.1`。末尾にスラッシュを付けない。同じクライアントの他のリダイレクト URL は残して構いません）
3. **Scopes**: 次の7つをすべて有効にします（`asset:read` はポータルで `asset` の Write を選ぶと自動で含まれます）。
   - `design:meta:read`
   - `design:content:read`
   - `design:content:write`
   - `asset:read`
   - `asset:write`（画像をCanvaにアップロードするために必要）
   - `brandtemplate:meta:read`
   - `brandtemplate:content:read`
4. クライアントシークレットを発行し、`CANVA_CLIENT_ID` と `CANVA_CLIENT_SECRET` をリポジトリ直下の `.env` に設定します。API の Worker にも同じ値を設定します。

## C. 認可（1回だけ）

```
pnpm --filter @ama/db canva:bootstrap
```

1. ターミナルを開いたままにします（ポート 8765 で5分間待機します）。
2. 表示された URL を開き、Canva Enterprise のユーザーで承認します。
3. 成功すると、ブラウザに "Canva auth complete" と表示され、ターミナルに "refresh token stored in the canva_tokens table" と出力されます。

Canva はリフレッシュトークンを**使うたびに更新（ローテーション）**します。そのため、最新のトークンは環境変数ではなく `canva_tokens` テーブルに保存されます。`CANVA_REFRESH_TOKEN` は初期値としてのみ使われます（任意）。インテグレーションを取り消した場合や、トークンが失効した場合は、このスクリプトを再実行してください。

> **注意:** 認可するときは、テンプレートを所有している Canva アカウントでログインしてください。別のアカウントで認可すると、アプリからテンプレートが見えません。

## B. ブランドテンプレートの作成（アカウントごと、または共有）

### 参考アカウントから作成する（任意）

**アカウント追加 → Canvaテンプレート → 参考アカウントから新しいテンプレートを作成** で行います。

1. 参考にする Instagram のプロフィールリンク（`https://www.instagram.com/<handle>` または `@handle`）を入力します。
2. 参考にするカルーセル**1投稿分**のスクリーンショットを、スライドの順番どおりにアップロードします（最大10枚）。サーバーから Instagram を直接読み取ることはできないため、構成（ページ数、各ページの役割、テキスト枠）はスクリーンショットから判断します。判断にはビジョンモデル（`gpt-4.1`、`OPENAI_API_KEY` が必要）を使います。スクリーンショットや API キーがない場合は、標準の8ページ構成になります。
3. 必要に応じて、素材の URL（ロゴや写真）とスタイルのメモを追加します。これらは下書きの指示書に書き込まれるだけで、Canva にはアップロードされません。
4. **Canvaに下書きを作成**（`POST /canva/template-drafts`）を押すと、生成した PDF を Canva に取り込み、**複数ページ・1080×1350 のデザイン**を作ります。推定したスライドごとに1ページで、各ページに項目名が書かれています。レスポンスには、編集リンク、Markdown の指示書、推定した構成が含まれます。
5. Canva で、参考アカウントのスタイルに合わせてページをデザインします。そのあと、下の「Canvaで作成する」の手順（項目名の設定と公開）に進みます。
6. モーダルに戻り、**公開したので一覧を更新**を押して、新しいテンプレートを選び、アカウントを追加します。テンプレート ID は、セクション D と同様にアカウント（`canva_template_id`）に保存されます。

Canva Connect API には、要素の追加、自動入力の項目名の設定、ブランドテンプレートの公開を行う機能がありません。そのため、手順5と6は手作業になります。

**制限:** アカウント作成時のチェック（`checkTemplate`）とコンテンツ生成エージェントは、現在、**21項目・8ページの固定構成**を前提にしています。ページ数が異なる構成で下書きを作ることはできますが、`slideFieldsSchema` とエージェントが可変構成に対応するまでは、アカウントに紐づける際に拒否されます。

### Canvaで作成する

仕様: [features/canva-template-spec.md](features/canva-template-spec.md)。要点は次のとおりです。

1. **8ページ・1080×1350（4:5）** のデザインを作成します。
2. **Data autofill** アプリで、すべてのテキスト要素に、次の21個の名前を**正確に**付けます。

   | ページ | 項目 |
   |---|---|
   | 1 表紙 | `s1_title`, `s1_sub` |
   | 2 共感 | `s2_head`, `s2_body` |
   | 3〜6 ポイント | `s3_num`, `s3_head`, `s3_body` … `s6_num`, `s6_head`, `s6_body` |
   | 7 求人紹介 / まとめ | `s7_label`, `s7_head`, `s7_body` |
   | 8 CTA | `s8_head`, `s8_cta` |

3. **画像を使う場合は、画像欄も追加します**（次の「画像欄を追加する」を参照）。
4. **ブランドテンプレートとして公開**します。素材は独自のもののみ使用してください（第三者のロゴやキャラクターは使用不可）。

項目ごとの文字数の上限は `@ama/shared` の `SLIDE_FIELD_LIMITS` で定義されています（現在のテンプレートのテキスト枠に収まる文字数です）。テキスト枠は、この上限の文字数が収まる大きさにしてください。

### 画像欄を追加する（アカウント作成時・画像を使う場合）

テンプレートは、スライドに画像を載せるための**画像欄**を持っている必要があります。アプリ側からは、画像欄の追加や位置の指定はできません。Canva Connect API が、すでにある欄へ値を入れることしかできないためです。そのため、**新しいアカウント（テンプレート）ごとに、1回だけ手作業**で追加します。

1. 画像を載せたいページ（例: 2〜6枚目）に、画像のプレースホルダー（フレーム）を置きます。位置と大きさは、ここで決めたものが毎回そのまま使われます。透明背景のPNGを使うと、キャラクターなどがきれいに載ります。
2. **Data autofill** アプリで、その画像要素を選び、データ欄名を `s{ページ番号}_image` にします（`s1_image` 〜 `s8_image`）。
3. 使うページぶんだけ繰り返します。全ページに置く必要はありません。
4. **ブランドテンプレートとして公開し直します。** 公開していないと、アプリは欄を認識できません。
5. ダッシュボードの **エージェント設定 → 画像** タブを開き直して、確認します。
   - 「テンプレートの画像欄: s2_image, …」と出れば成功です。
   - 画像（またはAI画像生成）を設定しているのに、「画像欄がありません」という赤い警告が出る場合は、欄が見えていません。1と2、そして4の公開をやり直してください。

画像欄は、画像を使わないアカウントでは不要です。その場合は、テンプレートのデザインがそのまま使われます。

複数のアカウントで**同じテンプレートを共有**すれば、この作業は共有ぶんの1回で済みます。デザインを変えたいアカウントだけ、テンプレートを複製してください（複製したテンプレートで欄名が引き継がれるかは、確認してから使ってください）。

### テンプレートの修正

生成したテンプレートは、**必要であれば Canva 上で修正できます**。このテンプレートが以降のコンテンツ生成に使われるため、修正は次の点に注意してください。

- **修正してよいもの:** 背景、色、フォント、装飾、イラスト、写真、各要素の位置や大きさ。
- **変えてはいけないもの:** 21個の**項目名**（`s1_title` 〜 `s8_cta`）、ページ数（8ページ）。項目名を消したり変えたりすると、アカウントへの適用時に「Template is missing autofill fields」と拒否され、生成もできなくなります。
- **文字数に注意:** Canva の自動入力はテキストを**縮小しません**。テキスト枠より長い文章は、枠からはみ出します。枠を狭くしたり文字を大きくしたりすると、`SLIDE_FIELD_LIMITS` の文字数が収まらなくなります。その場合は、上限の値とテスト（`slide-limits.test.ts`）も合わせて更新してください。
- **固定のテキスト:** 項目名を付けていないテキスト（`@yourHandle` やページ番号など）は、すべての投稿に同じ内容で表示されます。
- **公開し直す:** 修正したあと、Canva で再度ブランドテンプレートとして公開してください。アカウントでテンプレートを選び直す必要がある場合は、セクション D の手順で「テンプレートを適用」します。

エージェント設定の **Canvaで適用中のテンプレートを開く** リンクから、そのアカウントが使っているテンプレートを Canva で開けます。

## D. アカウントの追加

ダッシュボードの **アカウント追加** から行います。

1. Instagram のハンドル、投稿生成スケジュール、ターゲット、コンセプトを入力します。
2. ドロップダウンから **Canvaテンプレート** を選びます。認可した Canva ユーザーが見られるブランドテンプレートが一覧に表示されます。
3. 送信します。API が、テンプレートに21項目すべてがあるかを確認します。不足がある場合は、不足している項目名を示して拒否します。

これにより、アカウント（`POST /accounts`）と、ターゲットとコンセプトから作る最初のガイドラインが作成されます（空欄は `未設定` になります）。

> 作成時のチェックで確認されるのは、**21個のテキスト欄だけ**です。画像欄（`s{n}_image`）は必須ではないため、足りなくてもアカウントは作成できます。画像を使うアカウントでは、作成後に **エージェント設定 → 画像** タブで、画像欄が認識されているかを確認してください。

あとからテンプレートを変更するには、**エージェント設定 → Canvaテンプレート → テンプレートを適用** を使います（`PUT /accounts/:id/canva-template`、同じ検証が行われます）。

UI を使わずに直接設定する場合は、次の SQL を使います。

```sql
UPDATE accounts SET canva_template_id = '<ブランドテンプレートID>' WHERE id = '<アカウントID>';
```

シードされているアカウント `acc_001` には、Canva に存在しないプレースホルダー `tpl_wakaru_explainer_v1` が入っています。生成する前に、実際のテンプレートを選んでください。

## E. セットアップの仕上げとコンテンツ生成

1. **エージェント設定**: トーン、NGルール、CTA とハッシュタグの方針を設定し、参考資料を追加します。画像を使う場合は、**画像** タブで次も設定します。
   - **画像ライブラリ**: 「そのまま配置」の画像（ロゴなど。AIが内容に合うときだけ使います）と、「AI生成の見本」の画像を登録します。
   - **AI画像生成（共通ルール）**: 被写体・画風・色合い・背景など、毎回そろえたいことを書きます。空欄だとAI画像生成はオフです。
2. アイデア出しを実行し、アイデアを選んで **このアイデアでコンテンツを作成** をクリックします。
3. 投稿は `pending → generating_copy → rendering → ready` の順に進みます。8枚のスライド画像が、投稿の詳細パネルに表示されます。ハッシュタグは、投稿文（キャプション）の末尾に文字として入ります。

投稿文・スライド文・ハッシュタグの生成には、ミニモデル（`gpt-4.1-mini`）を使います。

## トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| 承認後、ブラウザに `127.0.0.1 refused to connect` と表示される | `canva:bootstrap` がすでに終了していた | 再実行し、5分以内に承認する |
| `redirect uri doesn't match any of the stored uris` | リダイレクト URL がインテグレーションに登録されていない | `http://127.0.0.1:8765/callback` を追加する（A の手順2） |
| 同意画面で `invalid_scope` | スコープが有効になっていない | 7つのスコープをすべて有効にする（A の手順3） |
| `Missing scopes: [asset:read]`（`asset:write`） | 保存済みのトークンに画像用のスコープが無い | ポータルでスコープを有効にし、`canva:bootstrap` を再実行する（C） |
| 画像タブに「画像欄（s1_image〜s8_image）がありません」と赤字で出る | テンプレートに画像欄が無い、または公開し直していない | 「画像欄を追加する」の手順で欄を追加し、公開し直す |
| 画像を選んだはずなのに、スライドに載らない | テンプレートに、そのページの `s{n}_image` が無い | 同上。載せたいページに欄を追加する |
| `Invalid brand template ID tpl_wakaru_explainer_v1` | アカウントがシードのプレースホルダーのまま | 実際のテンプレートを選ぶ（D） |
| `Template is missing autofill fields: …` | 要素に項目名が付いていない、または綴りが違う | Canva で名前を直し、再公開して、再適用する |
| テンプレートのドロップダウンに「テンプレート一覧を取得できません」と表示される | 認可がない、または期限切れ | `canva:bootstrap` を再実行する |
| `invalid_grant`（`Refresh token used twice` / `Token lineage has been revoked`） | リフレッシュトークンが2回使われ、Canva が認可を取り消した | API を再起動し、`canva:bootstrap` を再実行する。他の環境（別の開発サーバーや、`CANVA_REFRESH_TOKEN` を設定したデプロイ済み Worker）が同じトークンを使っていないか確認する |
| プレビュー画像が表示されない | 書き出した署名付き URL は期限切れになる | 投稿パネルの **プレビューを更新** を押す |
| 画像が `images.example.com` のプレースホルダーになる | Canva クライアントがモックモード（認証情報または Turso が未設定） | Canva の環境変数と Turso を設定し、API を再起動する |
| 文字が枠からはみ出す | 文章がテンプレートの枠に対して長すぎる | `SLIDE_FIELD_LIMITS` に合わせて文章を短くする。枠を変更した場合は、上限の値とテストも更新する |
